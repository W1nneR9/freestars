# MotoPulse — інтернет-магазин мотоекіпіровки

Сучасний односторінковий сайт магазину мотоекіпіровки з адаптивним дизайном, фільтрацією каталогу та каруселлю відгуків.

## Структура
- `index.html` — головна сторінка з секціями героя, каталогу, колекцій, пропозиції, відгуків та підписки.
- `assets/css/styles.css` — стилі з темною неонною естетикою, градієнтами та адаптивною версткою.
- `assets/js/app.js` — логіка для фільтрації товарів, рендеру каталогу, каруселі відгуків та мобільного меню.

## Запуск
Відкрийте `index.html` у браузері або підніміть локальний сервер:

```bash
python -m http.server 8000
```

Далі перейдіть за адресою [http://localhost:8000](http://localhost:8000) і відкрийте `index.html`.
